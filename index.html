01 / EDUCATIONAL DESKTOP PROJECTDOCUMENTED

Hospital Billing Management System

An educational Java AWT desktop application that records fictional patient details, calculates illustrative hospital charges, generates receipts and saves patient and billing records to a local MariaDB database through JDBC.

WHAT IT DOES
  • Captures patient details and billing inputs, then generates a sample bill.
  • Validates required fields, dates, contact numbers, amounts, discounts and demo tax values.
  • Uses BigDecimal for two-decimal monetary calculations.
  • Saves patient and bill records in related MariaDB tables using JDBC, prepared statements and transactions.
  • Retrieves recent saved bills and supports Enter-key navigation between form fields.

02 / TEAM-BASED IOT CONCEPTCONCEPT DOCUMENTED

Radiation Exposure Monitoring & Alert Concept

A student team concept exploring additional alerting for ionising-radiation work areas. The classroom demonstration used an ESP32 and a potentiometer to simulate changing sensor input; threshold logic activated a red LED and buzzer.

WHAT THE DEMONSTRATION SHOWS
  • Reads a manually adjustable analogue value from a potentiometer.
  • Uses the ESP32 to compare the simulated input with a configured threshold.
  • Triggers a red LED and buzzer as local visual and audible alerts.
  • Documents future possibilities such as a suitable radiation detector and a supervisor dashboard; these were not part of the demonstrated build.
